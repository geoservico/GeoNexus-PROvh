# GeoNexus 1.17.11.2 — Modo Assinante Protegido

Ao abrir projeto atualizado do Google Drive, o plugin desabilita as ações comuns do QGIS Salvar Projeto e Salvar Projeto Como, incluindo atalhos associados a essas ações. As ações são restauradas quando o plugin é descarregado.

**Limite:** isto é apenas uma restrição de interface, não DRM nem bloqueio de cópia. O projeto é baixado para disco e usuários com acesso ao computador podem copiá-lo, usar o console Python, outras ferramentas ou funções de exportação. Não protege arquivos públicos no Google Drive. O controle efetivo dos dados exige autenticação e autorização no servidor WMS.

Não foi alterada a autenticação HTTP Basic legada nem realizada validação do gateway Bearer Hotmart. Testar no QGIS 3.44.8 e observar as ações de salvar.
